# Annabel Art — Brand Spec v1

## Positioning
Contemporary figurative painting with an editorial, surreal edge. The brand disappears; the work is the brand. Every design decision defers to the paintings.

Reference: nikeadawi.se — simple, sophisticated, restrained.

---

## Wordmark
- Text only: `annabel art`
- Font: **Fraunces**, weight 300–400, lowercase, letter-spacing +0.02em
- No icon, no mark, no tagline in the logo
- Minimum size: 24px on screen, 12mm in print
- Clear space: one "a" height on all sides
- Never: outline, gradient, shadow, color, or set on a busy image

## Typography
| Role | Font | Weight | Size (desktop / mobile) | Notes |
|---|---|---|---|---|
| Wordmark | Fraunces | 300 | 28px / 22px | lowercase |
| H1 | Fraunces | 300 | 48px / 32px | line-height 1.1 |
| H2 | Fraunces | 400 | 32px / 24px | |
| Body | Inter | 400 | 16px / 16px | line-height 1.6 |
| Nav / labels | Inter | 400 | 14px | sentence case |
| Captions (title · medium · size · year) | Inter | 400 | 13px | mid gray |

Rules: two typefaces only. No bold body text. No all-caps except edition numbers.

## Color
| Token | Hex | Use |
|---|---|---|
| ink | #111111 | text, wordmark, buttons |
| paper | #FAF9F6 | page background |
| charcoal | #3A3A3A | secondary text |
| stone | #8A8A8A | captions, placeholder |
| mist | #E5E3DE | dividers, borders, hover |

No pure white, no pure black, no accent color. Ever.

## Layout
- Max content width: 1280px, side padding 48px desktop / 20px mobile
- Grid: 3 columns desktop, 2 tablet, 1 mobile; 32px gutters
- Generous whitespace — sections separated by 96px desktop / 64px mobile
- Header: wordmark left, nav right, sticky, transparent over `paper`
- Footer: email signup, Instagram, contact, © annabel art

## Imagery
Catalog shot (required on every piece)
- Square-on, camera parallel to canvas, cropped to the artwork edge
- Two lights at 45°, no glare, no shadow
- Same neutral wall for every shot
- Export 2000px longest edge, sRGB, JPG q85
- Displayed on `paper` background with 0 border — image is the tile

In-situ shot (originals only)
- Hung at eye level, natural indirect light, minimal room
- Used as second image on product page, never in the grid

No mockup frames, no filters, no watermarks.

## Voice
- Warm, confident, concrete. Short sentences.
- About page in third person. Newsletters in first person.
- Product copy is data, not prose: `Title · Oil on canvas · 24 × 36 in · 2026`
- Sold pieces stay visible, marked `Sold`
- Never use: "unique," "stunning," "one-of-a-kind," exclamation points

## Navigation
`Work · Originals · Prints · Commissions · About · Contact`

## Product Rules
Originals — qty 1, individual price, `Sold` badge, catalog + in-situ shot
Prints — size variants, edition size, signed & numbered, COA, paper spec
Commissions — 3 tiers with "from $", 50% deposit, timeline, revision policy

## Instagram
- Handle matches domain as closely as available
- Feed = catalog shots on `paper`, occasional process video
- Any text graphic uses Fraunces + Inter on `paper`, nothing else
- Bio link → site

## Do / Don't
Do: let one painting fill the hero. Leave space. Say less.
Don't: add color, add a logo mark, add a third font, add borders, add "art" clichés.
